# Local Music v0.15.0

6 November 2026. Output-independent Windows playback and reversible library organization.

## Included

- Windows playback can continue through a silent output when no physical audio output is available. Playback and listening history continue, and the player indicates the output state.
- Settings > Organize library provides lead-artist corrections while preserving original credits, reviewed song-copy links with a preferred copy, and reversible links between equivalent album entries with a chosen name, artist and cover.
- Confirmed song copies are kept from repeating in new playlists. Existing playlists can be reviewed and cleaned explicitly, with Undo. Source files and their tags remain unchanged.
- Live Recap and recommendations account for confirmed identities; raw listening history and previously saved Recap snapshots remain intact.
