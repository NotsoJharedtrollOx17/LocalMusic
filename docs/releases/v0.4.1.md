# Local Music v0.4.1

18 October 2026. Reviewed playbar fixes, integrated through `dev` into `main`. Packages and validation completed on 17 October; final release authorization was received on 18 October.

## Included

- Scrubbing previews the selected position locally, with one seek on release instead of repeated decoder jumps. Mouse, touch and keyboard controls preserve playing/paused state.
- Cancellation, focus loss and track changes discard unfinished scrubs. Trailing native range events cannot duplicate a seek.
- Tiny forward/backward adjustments retain their target until fresh native state arrives. Superseded polls and seek acknowledgements cannot overwrite newer state.
- Compact and expanded players share the thin progress track and circular thumb, with aligned compact timestamps.

The adaptive Adapt Sound features from v0.4.0 remain included. Earlier tags and release archives are preserved.

## Validation and distribution

See [verification](../verification.md) for actual frontend, browser, native and package results. Actual paused Windows seek stability has been checked; Android device/background reliability, physical-headphone acceptance and measured performance remain separate gates.

No Git remote is configured. This is a local annotated release with ignored Windows portable debug ZIP and signed Android ARM64 development APK artifacts. It is not a production-signed hosted distribution.
