# Local Music v0.3.0

14 October 2026. Third local development baseline, integrated through `dev` into `main`. Earlier release tags remain unchanged.

## Included

- Compact Library navigation with the logo, Search and an actions menu; separate Edit, Sound options and Settings flows.
- Automatic Recently added, Recently played, Most played and Favorites collections alongside editable playlists.
- Restored filtering and sorting, consistent playlist controls, centered compact playback controls and circular collection loading indicators.
- Always-active nine-band EQ, 63 Hz through 16 kHz, with -10 to +10 dB controls. Normal, Pop, Rock, Jazz, Classical and automatically saved Custom replace the previous switch, preamp, boost and preset-management controls.
- Separate Equalizer and Adapt Sound views, aligned channel diagrams, stable preparation and Yes/No controls, automatically repeating three-beep bursts and no replay button.
- English/Spanish, dialog focus, short-window layout, saving feedback and navigation refinements. The original guidelines and reference images are preserved under `agents/`.

## Calibration limitation

Adapt Sound currently records the first heard level and derives gains relative to each ear's 1 kHz reference. Yes ends that frequency; No raises the next level. Hearing every initial tone can produce a flat profile because the current protocol does not resolve quieter responses. The provisional setup chart does not change saved audio processing. An original adaptive calibration rewrite is planned separately and is not shipped in this baseline.
