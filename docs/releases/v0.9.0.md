# Local Music v0.9.0

26 October 2026. Reviewed music visualizers, integrated locally through `dev` into `main`.

## Included

- Now Playing opens a dedicated Visualizer view with Spectrum, Geometry and XMB wave modes, remembered mode, track information, seek and minimal playback controls. EN/ES, keyboard/Back, focus restoration and responsive light/dark/system themes are supported.
- Spectrum maps orange bass to blue treble with smooth bars and peak markers. Geometry adapts Abraham Jhared Flores Azcona's MIT-licensed *Origin of Symmetry* artwork using its Lorenz trajectory and rectangle mapping. XMB layers four ribbons moving at different rates and directions.
- Animation starts automatically after a short warm-up. Pause/completion lowers Spectrum to baseline, collapses Geometry inward, and flattens XMB into a stationary line; resume grows the scene back. Reduce Motion uses gentler automatic movement by explicit user choice. No Animate button or full-canvas pause fade remains.
- Owned PCM is sampled after EQ/limiting on Windows, Android and browser preview. Bounded background analysis and adaptive 60/30 fps rendering preserve the audio path; transient analysis is not recorded, exported or included in listening history. Visibility/minimize cleanup, native leases and playback-only screen-awake requests are included.
- Existing EQ, library, queue, privacy, Your Recap and Android listening-journal behavior are retained.

## Validation and boundaries

Release gates passed: 68 frontend unit tests, 73 browser journeys, 19 Rust core tests, 16 native Rust tests and seven freshly executed Kotlin tests. See [verification](../verification.md) for package hashes and exact evidence. CPU/frame targets, battery/thermal behavior, wired/Bluetooth synchronization and Galaxy Note10 acceptance need physical measurements. Earlier desktop stress profiling exceeded the incremental CPU target; adaptive controls do not establish that target as met. Native audible playback, Android runtime/background and manual screen-reader acceptance remain separate from browser/build evidence.

No Git remote is configured. This is a local annotated release with a Windows portable development ZIP, a signed ARM64 development APK and SHA-256 checksums. It is not production-signed hosted distribution. Earlier tags/packages, historical plans, recordings and reference images are preserved.
