# Local Music v0.6.0

25 October 2026. Reviewed player, collection and responsive-layout update, integrated locally through `dev` into `main`.

## Included

- A centered Now Playing view with square artwork and centered song/artist text. Queue, Favorite and Add to playlist share one row above the shared progress slider and transport controls.
- A top-right player menu containing track navigation/details and Sound options. Exclude from recap is second-to-last and Remove from Library is last where available. Pending privacy writes retain checked/busy/error behavior. Ordinary song menus remain unchanged.
- Consistent passive collection counts for Songs, Albums, Artists and Playlists, with no title-to-count flash during tab changes. Favorites selection, sort recovery and opening focus are stable.
- Aligned playlist overview headings/creation controls, predictable narrow-screen detail actions, balanced player headers, and consistent queue scrolling.
- Zoom remains available. Short views scroll the complete player beneath its reachable header instead of squeezing artwork away or clipping controls. Normal views retain anchored playback controls. Recap artwork, album grids, settings and EQ resize/wrap without forcing a wider page.

No DSP, calibration, public MusicApi, persistence or listening-accounting changes are introduced. Existing adaptive Adapt Sound, seek behavior and privacy rules remain included; earlier tags and local release archives are preserved.

## Validation and distribution

See [verification](../verification.md) for the actual frontend, browser, Rust, Kotlin, Windows and APK results. Browser/Windows tests and APK packaging do not establish Android background reliability, physical-headphone acceptance, manual screen-reader behavior or measured performance.

No Git remote is configured. This is a local annotated release with ignored Windows portable debug ZIP and signed Android ARM64 development APK packages, plus SHA-256 checksums. It is not a production-signed hosted distribution.
