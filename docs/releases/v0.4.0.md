# Local Music v0.4.0

15 October 2026. Reviewed adaptive Adapt Sound integration, released locally through `dev` into `main`.

## Included

- Original 36-response calibration with alternating ears and bounded quieter/louder follow-ups. It replaces the first-heard protocol shipped in v0.3.0.
- Animated response estimates during setup, followed by the actual proposed independent-channel EQ and matched-loudness comparison. Flat results and limited coverage are distinguished.
- Stable, compact setup controls without replay or tone-details clutter. Focus loss and lease expiry stop tones and preserve progress in memory; Continue explicitly resumes. Close, Back, Stop and output changes cancel unfinished setup.
- Stale-trial protection, retained legacy profiles, derived-only profile metadata and zero setup-induced listening history. Browser comparison generation runs in a cancellable worker.

## Known issues and boundaries

The user reported jarring playbar audio, potentially associated with repeated seeks while dragging. Investigation continues on a separate development branch; this release does not claim that issue is fixed.

This is an original music preference calibration, not Samsung's proprietary algorithm or a clinical hearing measurement. Physical headphone, Android device/background, accessibility and performance acceptance remain separate gates. See [verification](../verification.md) for actual checks and build evidence.

No Git remote is configured. The annotated `v0.4.0` tag and ignored Windows portable debug ZIP / signed Android ARM64 development APK follow the existing local-release convention. These are development packages, not a production-signed hosted release.
