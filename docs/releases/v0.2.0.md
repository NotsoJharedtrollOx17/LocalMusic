# Local Music v0.2.0

10 October 2026. Second development baseline, integrated through `dev` into `main`. The `v0.1.0` tag retains the first baseline.

## Included

- Phase 2 music flow: responsive Library navigation, artist Songs/Albums views, expanded player and queue, grouped search, contextual menus, selection, sharing and persistent removal/Undo.
- Focused React components and Rust modules, startup/loading safeguards, device-based recap calendar and app-styled controls.
- Working ten-band application equalizer on Windows, Android and browser preview, built-in and custom presets, Treble boost, independent preamp fader and temporary bypass.
- Personal music profiles with three-beep setup steps, interruption recovery, simultaneous channel-curve display, direct selection, full-strength application and persisted defaults.
- Presets/profile selection preserve manual preamp. No automatic global headroom attenuation; the linked peak limiter remains for clipping control.
- The original UX/UI guideline is now tracked in `.AGENTS/Codex-UX-UI-Design-Reference.md`.

## Validation and limits

See [verification](../verification.md) for actual frontend, affected browser, Rust, Kotlin and native-build results. Browser measurements confirm processing for controlled fixtures; they do not prove native headphone behavior or Android background reliability.

Android runtime acceptance awaits a connected emulator/device. Physical stereo-headphone checks, native output/interruption behavior, device screen readers and measured performance remain pending. Personal sound is a music preference feature; no clinical or hearing-protection claim is made.

This repository has no configured Git remote. The release is recorded locally by the annotated `v0.2.0` tag; no hosted release or remote publication is implied. Native debug artifacts remain ignored development outputs, not a production-signed release distribution.
