# Local Music v0.8.0

26 October 2026. Reviewed Your Recap update, integrated locally through `dev` into `main`.

## Included

- Your Recap / Tu resumen replaces the yearly-only presentation. Weekly, Monthly and Yearly select the current calendar period, remember the timeframe and refresh automatically. Weeks begin Monday and display localized ISO week numbers and week-years. Date dropdowns and previous/next-period arrows are removed.
- Native and browser recaps use matching calendar boundaries, honest coverage, daily/monthly buckets and starting-period qualified-play attribution. Existing listening, pause, seek and exclusion rules remain unchanged. Device-zone synchronization and calendar arithmetic cover DST and midnight transitions.
- Top-three songs, artists and albums use descending rank emphasis. Songs and albums include cover artwork; artists and albums have independent story cards in a seven-step sequence.
- The numbered top-ten song list can be played or explicitly saved as an editable, period-named playlist. Ranking order has no per-artist cap. Unavailable and removed entries remain visible in rankings but are excluded from playback and saving.
- Story and Feed PNGs follow the current period and recorded rankings, preserving dimensions, privacy checks and accurate save/cancellation feedback. Existing yearly/schema-two snapshots remain readable and frozen. The Save snapshot button is removed; neither snapshots nor playlists are saved automatically.
- Ordinary EQ, playback, Android's durable listening journal and the established library/player menus remain intact. Application/window metadata now uses Your Recap.

## Validation and distribution

See [verification](../verification.md) for actual release tests, native inspection, package hashes and remaining acceptance gates. Android runtime/background behavior, physical-device/headphone use, manual screen-reader checks and measured performance require separate evidence.

No Git remote is configured. This is a local annotated release with an ignored Windows portable development ZIP and signed ARM64 development APK plus SHA-256 checksums. It is not a production-signed hosted distribution. Earlier releases, historical plans, source recordings and reference images remain preserved.
