# Local Music v0.14.0

1 November 2026. Native Windows application menus and an independent About window.

## Included

- A native File, Library, Playback, Window and Help menu on the main Windows window, with English and Spanish labels and keyboard shortcuts.
- An independent About window that follows the app's language and theme while the Library remains available.
- The Library actions icon retains Edit, Equalizer and Settings. Native menu navigation changes Library tabs without leaving an extra focus frame; ordinary keyboard focus remains visible.
- Playback menu state follows the shared player, and selecting Queue switches an already detached player into Queue.
- Android and browser preview retain their existing controls and in-app media views.
