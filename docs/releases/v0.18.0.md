# Local Music v0.18.0

15 November 2026. Reviewed Android UI stabilization.

- Compact Queue rows omit album/year clutter and place editing controls inline.
- Touch menu highlighting and card press cancellation are consistent; tab entry and snap-back share one animation owner.
- Equalizer controls center beneath the header; Visualizer modes share one segmented row.
- Phone titles are more compact. About credits Abraham Jhared Flores Azcona in English and Spanish.

See [verification](../verification.md) for the 111-unit-test, Rust/Kotlin, 211-browser-case and Note10+ evidence. The reviewed feature was built and installed with version 0.17.0 before the release metadata bump. Those artifacts are not v0.18.0 packages. This release integration does not rebuild or publish binaries. Native off-screen tab-strip ergonomics and the remaining runtime/accessibility gates remain documented separately.
