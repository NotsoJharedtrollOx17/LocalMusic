# Local Music v0.12.0

31 October 2026. Reviewed inline Library search, integrated locally through `dev` into `main`.

## Included

- Search filters the current Library tab or collection, using the existing rows, cards and contextual actions. Main-tab queries are retained; opened collections start clear and Back restores the parent search.
- Song, album and artist searches prioritize primary names before secondary metadata, across the complete catalog before pagination. Collection track order is preserved.
- Desktop search opens beside its icon; narrow views place it below the tabs. The heading shows matching/total counts. Outside clicks collapse the field while keeping its filter; the toolbar X clears it with a brief reset transition and accessible focus restoration. Reduce Motion clears immediately.
- Playlist-name search updates immediately in one counted grid, with custom matches first and matching defaults afterward. Clearing restores the usual subdivisions and playlist creator. Default names follow the current language; custom Rename/Delete actions and playlist membership remain intact.
- Stale responses, loading/error recovery, scoped playback and editing, keyboard navigation and localized layouts retain their existing safeguards.
