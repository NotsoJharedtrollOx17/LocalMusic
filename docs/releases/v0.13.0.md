# Local Music v0.13.0

31 October 2026. Detached Windows player, visualizer and equalizer, integrated locally through `dev` into `main`.

## Included

- Keep Now Playing/Queue, Visualizer and Equalizer in independent, resizable Windows windows. Visualizer opens directly from Now Playing; Equalizer opens directly from Library or Now Playing.
- Close or Back dismisses a child without reopening a popup; Return to main restores its view. Optional Always on top, remembered session bounds, shared player/EQ state and readable size limits remain available.
- Android and browser preview retain their in-app views.

## Validation and distribution

Final checks passed: **101 frontend unit, 114 browser, 28 Rust core, 24 native Rust and 9 Kotlin tests**. Windows and ARM64 Android development builds passed; version metadata, frozen frontend assets, APK signature and packaged native-library hashes were verified. See [verification](../verification.md) for evidence and remaining device acceptance. This is a local annotated release with development packages, not production-signed hosted distribution.
