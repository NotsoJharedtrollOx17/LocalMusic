# Local Music v0.5.0

20 October 2026. Reviewed contextual-menu and Favorites update, integrated through `dev` into `main`.

## Included

- Focused song action menus: Add to playlist, Track details, Go to album, Go to artist and Remove from Library where applicable. Share audio appears only on platforms with a sharing chooser; Save Copy is removed from song menus.
- Consistent menu ownership, keyboard/focus behavior and collection-scoped Edit. Album and artist navigation restores its originating view, scroll and focus; collection details have one centered heading.
- Empty Favorites is distinct from an empty library. Loading, sorting and delayed reads cannot substitute an Import splash or hide Albums/Artists. Playlist generation uses the whole catalog; Songs pagination retains its filtered count.
- English/Spanish empty-Favorites guidance and an All music recovery action with clearer spacing.

Previous playback, EQ and adaptive Adapt Sound features remain included. No DSP, calibration or listening-accounting changes are part of this release. Earlier tags and local archives are preserved.

## Validation and distribution

See [verification](../verification.md) for actual release checks and package results. Browser and Windows evidence do not establish Android background reliability, physical-headphone acceptance or measured performance; those remain separate gates.

No Git remote is configured. This is a local annotated release with ignored Windows portable debug ZIP and signed Android ARM64 development APK artifacts. It is not a production-signed hosted distribution.
