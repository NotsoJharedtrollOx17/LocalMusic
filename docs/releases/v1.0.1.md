# Local Music v1.0.1 release candidate

Android Library swipes allow for finger jitter before moving a pane. The active tab indicator follows horizontal drags, and Your Recap uses the same left anchor as the other tabs. Song touch feedback appears on a confirmed tap. Short flicks have a larger minimum travel distance to switch tabs. Detail views use directional motion. Now Playing expands from the mini-player and follows vertical drags before settling. Equalizer controls start near the heading, and Back returns to the screen that opened it. Android WebView zoom gestures are disabled, and system font scaling is supported.

Android stores generated artwork in the app cache. Existing installations migrate recognized cover files on a background worker. Android can reclaim these files and Local Music can rebuild artwork from available sources. Imports create one master thumbnail per embedded image and derive smaller images on demand. Artwork for the current track receives priority. A fixed-size placeholder holds the layout while artwork decodes, and Now Playing can use the cached small cover during the upgrade. Warm group navigation reuses track lookups for the current catalog revision.

Android Recap Export uses a smaller preview. Story and Feed use a larger `local.` stamp in the lower-right corner. Save and Share use separate progress labels, render the selected format at full resolution, and check the current privacy state before delivery.
