# Local Music v1.0.1 release candidate

Android Library swipes allow for finger jitter before moving a pane. The active tab indicator follows horizontal drags. Short flicks have a larger minimum travel distance to switch tabs. Detail views use directional motion, and Now Playing slides from the mini-player. Equalizer controls start near the heading. Android WebView zoom gestures are disabled, and system font scaling is supported.

Android stores generated artwork in the app cache. Existing installations migrate recognized cover files on a background worker. Android can reclaim these files and Local Music can rebuild artwork from available sources. Imports create one master thumbnail per embedded image and derive smaller images on demand. Warm group navigation reuses track lookups for the current catalog revision.

Android Recap Export uses a smaller preview. Save and Share render the selected format at full resolution and check the current privacy state before delivery.
