# v1.0.0 - First official release

Local Music brings the reviewed offline Android/Windows player together with consolidated documentation and verified release automation.

- Complete local Library browsing/search, reversible artist/song/album organization, editable playlists and explicit Familiar/Balanced/Explore generation.
- Shared playback/queue, live Equalizer, post-EQ visualizers and desktop detached windows/native menus.
- Weekly/monthly/yearly Your Recap with artwork, truthful history coverage, privacy-checked PNGs, Gallery saving and system sharing.
- Centered branding, orange-period launcher icons and cohesive responsive controls.
- Optimized native release builds, permanent Android signing, Windows installer/portable packages and SHA256SUMS.

## Installing

Windows x64 packages are unsigned and require WebView2. Android ARM64 requires Android 8/API 26 or later. The permanent Android release certificate differs from earlier debug builds: those cannot update in place. Back up/review private app data before a clean release installation; old history does not automatically migrate.

## Evidence and limitations

See [verification](../verification.md) for the exact hosted workflows, tested commits, packages and runtime results. Browser/fixture tests do not establish battery/thermal behavior, controlled synchronization/latency or manual screen-reader acceptance. Recommendations measure local listening/metadata/spectral resemblance, not inferred mood or semantic understanding. No account or streaming service is required.
