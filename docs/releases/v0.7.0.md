# Local Music v0.7.0

25 October 2026. Reviewed removal of Adapt Sound, integrated locally through `dev` into `main`.

## Included

- Equalizer / Ecualizador opens directly from Library and Now Playing menus. The nine editable bands, Normal/Pop/Rock/Jazz/Classical/Custom presets, automatic Custom saving and live updates remain.
- Removed Adapt Sound onboarding, profiles, calibration tones, comparison workers, commands and profile processing across browser, Windows and Android.
- Existing installations upgrade sound configuration to version 2 at the same storage key. Saved personal profiles are deleted; the last ordinary EQ and saved Custom settings are retained. Personal curves are not converted into Custom. Failed migration writes keep processing inactive and expose retryable errors.
- Playback, listening history, privacy, Queue/Heart/Add controls and the established player/menu layouts are preserved.

## Validation and distribution

See [verification](../verification.md) for measured test, migration, Windows and APK results and remaining acceptance gates. Android runtime/background behavior, physical-headphone use, manual screen-reader checks and performance require separate evidence.

No Git remote is configured. This is a local annotated release with ignored Windows portable debug ZIP and signed ARM64 development APK, plus SHA-256 checksums. It is not a production-signed hosted distribution. Historical plans, releases, recordings and reference images remain preserved.
