# Local Music v0.17.0

14 November 2026. Phone interface, navigation and library stability improvements.

## Included

- Refined phone Library tabs, touch feedback, continuous scrolling, selection and collection layouts; warmed catalog data and bounded rendering improve navigation of larger libraries.
- Refined the mini-player, Now Playing transition, equalizer, Settings and library organization views. Album and Artist details omit repeated row metadata.
- Streamlined phone playlist creation while retaining its blend, filters and preview.
- Android library scans skip known available music before metadata/artwork extraction; repeated imports no longer inflate the imported count. Explicit folder imports can refresh metadata.
- Playback controls publish an authoritative update after a command. The existing seek, history and privacy rules remain.
